# LUMEN — витрина AI-блогеров

Mobile-first прототип лендинга с каталогом из четырёх AI-персонажей. Чистый HTML/CSS/JS, без сборки и зависимостей.

- Карточки блогеров с портретами, сгенерированными нейросетью
- Профиль в модальном окне: мини-лента публикаций с лайками и демо-диалог с быстрыми ответами
- CTA «Перейти в Telegram» в шапке, на первом экране, в профиле и в отдельном блоке

Ссылка на Telegram задаётся константой `TG_URL` в начале `script.js`, данные персонажей — массивом `bloggers` там же.

Запуск: откройте `index.html` в браузере.
